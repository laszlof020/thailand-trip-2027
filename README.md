# Thailand Trip 2027

Itt gyűjtjük össze az utazással kapcsolatos összes fontos információt.

## Fontos időpontok

- **Jegyvásárlás időpontja:** 2026. november 6. 18:00 (budapesti idő)

## Fejlesztés

```bash
npm install
npm run dev
```

Az időpontok a `src/tripData.js` fájlban vannak. A `main` ágra pusholt változások automatikusan kikerülnek GitHub Pagesre.
